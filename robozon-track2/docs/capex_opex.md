# Приложение A2. Оценка CAPEX / OPEX

CAPEX (Capital Expenditure — капитальные затраты, «купить и построить»),
OPEX (Operational Expenditure — операционные затраты, «содержать в год»).
Диапазоны — по открытым прайсам поставщиков класса оборудования,
курс-нейтрально, точность ±30 % (стадия концепта).

## CAPEX

| Статья | Кол-во | Оценка, млн ₽ |
|---|---|---|
| Роботы АМР-Т5 (класс Libiao/Geek+) | 1 380 × ~0,55 | 760 |
| Мезонины 3 яруса (сталь, 400 кг/м²) | 8 300 м² | 250 |
| Индукционные станции с DWS | 60 × ~3,5 | 210 |
| Шахты с замедлителями | 1 254 | 63 |
| КТЯ-станции (тандем, датчики, толкатель) | 416 × ~0,45 | 187 |
| Конвейеры (подача 12 + отвод 20) | ~1,1 км | 110 |
| Формовщики коробов | 5 × ~9 | 45 |
| WCS/FMS/ИТ/сеть/СКУД | — | 120 |
| Электрика, пожарка, монтаж, ПНР | — | 190 |
| **Итого** | | **≈ 1 935** |

Для сравнения: 8-кольцевой кросс-белт с 3 200 станциями на 20 000 м²
оценивается в 2,6–3,2 млрд ₽ при худшей гибкости.

## OPEX (год)

| Статья | Оценка, млн ₽/год |
|---|---|
| Электроэнергия: 607 кВт × 6 000 ч × 7 ₽ | 25,5 |
| ЗИП и сервис роботов (4 % парка/год + ТО) | 45 |
| Персонал смены (операторы WCS 2, техники 4, reject 4, расходники 4) × 4 смены | 84 |
| Расходники (короба — в себестоимости отгрузки), прочее | 12 |
| **Итого** | **≈ 167** |

Себестоимость сортировки при 600 млн товаров/год:
(амортизация 1935/10 + 167) / 600 ≈ **0,60 ₽/товар**.
